❌ 残念ながら動作しません

【ブラウザがGPUを認識しない場合の復旧手順】
GPUに問題があるとChromeは安全のためWebGPUを「ソフトウェアのみ」に切り替えることがあります。
以下で復旧する場合があります:
1. アドレスバーに chrome://settings/system と入力
2. 「可能な場合はハードウェア アクセラレーションを使用」を確認
　・OFFなら → ONにする
　・ONのままなら → 一度OFF→再起動→ON→再起動
　(このトグル操作で、GPUクラッシュのカウンターがリセットされます)
3. chrome://gpu を開き、WebGPUの行が「Hardware accelerated」に戻っていれば成功
4. このページに戻って、Ctrl+Shift+R(強制再読み込み)してから再度診断
【このデモの動作要件】
・Windows PC + Chrome / Edge(最新版)
・WebGPU対応グラフィックボード(VRAM 8GB以上推奨)
例: RTX 3060以上 / RX 6600以上 / Intel Arc
・スマホ・タブレットには非対応
